# IHM Farm — painel de fazenda em Flutter

![Flutter](https://img.shields.io/badge/Flutter-02569B?style=flat-square&logo=flutter&logoColor=white) ![Dart](https://img.shields.io/badge/Dart-0175C2?style=flat-square&logo=dart&logoColor=white) ![Institucional](https://img.shields.io/badge/Institucional-6b7280?style=flat-square)

Projeto institucional em **Flutter**: um painel (*dashboard*) para acompanhar uma fazenda, pensado como interface homem-máquina (IHM) simples e legível.

## Como executar

O projeto é um único `main.dart`. Para rodar:

```bash
flutter create ihm_farm
cp main.dart ihm_farm/lib/main.dart
cd ihm_farm && flutter run
```
